# API-Project
This project is a complete manual API testing practice setup built using JSON Server. It simulates a mini e-commerce backend with endpoints for Users, Products, Cart, and Orders. The goal of this project is to help beginners and 1–2 year QA engineers practice GET, POST, PUT, PATCH, and DELETE requests using Postman.
What This Project Covers

Setting up a mock REST API using JSON Server

Working with realistic data in db.json

Testing CRUD operations across all endpoints

Performing positive & negative test cases

Understanding expected vs. actual results

Preparing a QA portfolio-ready API testing project

📌 Endpoints Included

GET /users

GET /products

GET /cart

GET /orders

POST /users, /cart, /orders

PUT /cart/:id, /products/:id

DELETE /cart/:id, /orders/:id

🧪 What You Can Practice with This Project

API Testing using Postman

Response validation

Error validation (404, 400, 500 scenarios)

CRUD testing

Bug reporting

Writing test cases & scenarios
